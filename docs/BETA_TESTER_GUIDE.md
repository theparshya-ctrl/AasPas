# AasPas Beta — Tester Instructions

1. Install **AasPas BETA** APK (shared by the team).
2. Open the app — it connects automatically (no VPN, no Tailscale, no special Wi‑Fi).
3. Tap **Register** and create an account.
4. Choose **Customer** or **Shop Owner**.
5. Use the app normally: browse offers, search, view shops, save favorites.
6. If something breaks, send:
   - Screenshot
   - App version (Settings or About — **AasPas BETA v0.1.1**)
   - What you were trying to do

**Shop owners:** after registering, complete shop onboarding; offers require admin approval before customers see them.

**Do not share** your password. Admin accounts are created by the platform team only.
